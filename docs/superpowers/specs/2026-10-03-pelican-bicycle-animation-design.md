# 鹈鹕骑自行车 SVG 动画设计

## 目标

创建一个可直接在浏览器中打开的独立 HTML 页面，使用内联 SVG 绘制一只鹈鹕骑自行车的 2D 动画。

## 视觉与交互

- 暖色纸张质感背景，中央展示橙白色鹈鹕与复古自行车。
- SVG 分层绘制鸟身、头部、长喙、翅膀、车架、车轮、脚踏和道路。
- `requestAnimationFrame` 驱动连续动画：车轮与脚踏旋转、鹈鹕身体上下起伏、翅膀轻摆、道路和背景线条横向移动。
- 页面提供暂停/继续和重新开始按钮；按钮状态与动画状态保持同步。
- 画面使用 `viewBox` 自适应窗口，在窄屏中保持主体完整可见。

## 文件边界

- `site/pelican-bike.html`：页面结构、SVG 图形、样式和动画控制逻辑全部内聚于此，打开文件即可运行。

## 技术约束

- 只使用原生 HTML、CSS、SVG 和 JavaScript，不新增依赖。
- 动画不依赖外部图片、字体或网络资源。
- 遵循 `prefers-reduced-motion`：用户请求减少动态效果时保留静态画面并停止循环动画。

## 验收标准

1. 直接打开 `site/pelican-bike.html` 能看到完整鹈鹕、自行车和背景。
2. 初始状态下车轮、脚踏、鸟身、翅膀和背景至少有一处可观察变化。
3. 点击暂停后动画停止，再点击继续恢复；重新开始将时间归零并恢复初始姿态。
4. 页面在桌面和窄屏视口中无水平溢出，主体不被裁切。
5. 页面无控制台错误，SVG 元素和按钮具备可访问标签。
