## 全局约束

- 本轮不修复业务代码，不打标签、不推送、不修改仓库可见性。
- 第一阶段选择公开源码研究预览，不发布生产安装包，不建议部署到公网或接入真实资金。
- 后续发布前核验示例不注入 signer、不启用支付自动化、不授予文件读写能力，使用全新测试数据目录。
- 不能仅删除当前敏感文件而忽略 Git 历史，也不能用 git push --mirror 发布所有本地引用。
- 不改写开发分支历史。必要的公开快照使用独立临时导出目录并说明历史来源与删减范围。
- 不伪造外部门禁证据，不删除生产门禁来让预览版本通过。
- 外部账号、公开署名、仓库归属和可见性由用户确认；不在计划中假定这些信息。
