## 目标与范围

对象是 `src/noyra/web` 的实际运行实例公开页面，不是 GitHub Pages 项目介绍站。用户已授权在 PR #19 测试期间并行推进。#19 的提交留在原分支，本阶段不改变其CI修复、不部署服务器。

先完成阅读与表达，再单独实施访客账户、持续交流与协作。当前交付不显示尚不存在的登录、私信、通知、投稿查询或报酬入口；普通人阅读、留言无需管理员身份。

## 结果与证据

### A / C 导航、文案与参与

主导航收敛为首页、日记、项目、留言、关于；运行细分类放进原生details，访问旧hash时自动展开，15种旧路由和规范阅读链接保留。移动端提供首页/日记/项目/留言四个直接入口。首页三条入口都指向已存在功能，没有注册/私聊/通知空壳。

文案使用具体交流语句。普通访客不再被指引到管理台进行私密交流；来源继续区分主体原文、管理者独立摘要、未验证访客署名、运行记录，SPA与服务端独立文章页的双语词汇同步。真实阶段与友好称谓并列，不生成“梦境”“整理一天”或醒来承诺。

### B 首页内容与性能

实际浏览发现最近三条时间线很容易全部是生命周期转换。因此在现有overview中增加可选`writing`（最多一条已有公开日记列表投影），不改变`recent`三条的语义；旧客户端可忽略，新客户端兼容字段缺省。仍是一条HTTP总览请求、30秒刷新周期，额外读取受同一请求SQL/时间/字节预算约束；不调用模型，无schema或权限变更。

首页依次提供最新公开日记、公开项目/目标、近期记录与留言邀请。没有日记时准确说明“日记还没有公开”，不把阶段记录存在说成“没有活动”。卡片仅使用列表摘要，不用全文当缺省摘要；Markdown标题符仅在摘要中整理，正文原文保留。相同数据刷新不替换正文DOM，保留读者焦点，避免无变化重绘。

### D 复审与实际验收

- Node前端完整集合：126 passed（原116项，增加10项行为覆盖）。覆盖可选新/旧总览、独立writing、XSS/署名、空状态/筛选、旧路由、幂等/草稿、刷新不重绘与来源区分。
- Python公开面、HTTP、SSR阅读、错误处理、帖子容量/审核、可视合同：143 passed、26 subtests passed（407.71秒）；新增“阶段记录不能挤走公开日记”用例已通过。
- 全仓Ruff、Ruff format（704文件）及Mypy（442文件）通过；JS语法与OpenAPI语法检查通过。没有运行本分支整仓后端全量，不将专项等同全仓。
- 本地实际HTTP实例完全使用隔离合成数据，模型/资金/通信未接入。375/430/768/1024/1440五种宽度各检查首页/日记/项目/留言/投稿/关于/生命周期，35个视图无横向溢出；另查390宽英文深色和中文浅色。
- 浏览器实际翻页20→25条、打开正文、返回恢复25条；独立英文深色文章页来源与返回入口一致。无变化刷新保留原正文节点；总览503不隐藏独立成功的日记列表。
- 空日记实例仍显示真实阶段记录及留言入口；验证码真实生成，使用仅测试夹具记录的合成答案完成HTTP201提交，草稿清空，恶意HTML未执行。原始验证码/临时数据不进入仓库。
- 图片复核：本地合成实例的桌面、手机、中英/明暗、空状态及留言截图保存于本机`output/playwright/runtime-public-*.png`，没有把合成经历发布到真实实例。

## 修复风险复核

| 问题 | 原因及触发 | 影响/优先级 | 修复风险与防回归 |
| --- | --- | --- | --- |
| 首页只有运行分类 | 导航直接展示所有后台式分类，读者首次进入缺少起点 | P2体验 | 低；只调整层级，全部hash及规范文章地址保留 |
| 日记被阶段变化挤出首页 | overview最近三条混合排序；连续启停/休眠后全是stage | P2体验 | 中；增加有界且可选的已有公开投影，空body、主体过滤、原recent语义及请求预算保持 |
| 访客误入管理台 | 公开留言隐私说明把私聊指向operator入口 | P2权限理解 | 低；明确无私信，保留维护者入口但不授予访客任何管理会话 |
| 独立文章与SPA命名分裂 | 分类及来源文案在JS/Python各维护一份 | P2一致性 | 低；同步词汇并保留词表一致性测试；来源仍不能冒充主体原话 |
| 自动刷新影响阅读 | overview响应即完整重绘正文 | P3体验/成本 | 低；相同输出不替换DOM；数据/主题/语言变化仍更新，浏览器验证节点保留 |

没有调整署名认证、审核决策、验证码、限流、幂等或隐私白名单。发现的浏览器旧资源缓存导致预览旧版，通过验收时禁用测试浏览器缓存解决，未把测试缓存当作后端功能故障。生产升级后访问可能受既有五分钟静态资产缓存影响。账号功能的风险高于本阶段，继续独立实施。
