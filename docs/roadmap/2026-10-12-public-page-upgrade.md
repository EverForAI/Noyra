# 公开页面升级实施与验收

日期：2026-10-12。基线：`a27354a`；分支：`codex/public-page-upgrade-20261012`。

用户采纳公开页面建议，明确暂不实施「可核验性与公开证据」。因此不增加证据页、manifest、公开证据导出或证明能力。聊天删除继续关闭。既有审计未关闭问题不会由本轮顺带修改。仅本地实现、验证和提交；不部署、不调用付费资源、不执行真实通讯或资金操作。

## 公开内容原则

已发布日记仍由主体选择，访客帖子仍须既有审核。新增目标等内容默认全部私有；管理者手动撰写并明确批准独立的公开摘要，界面标为「管理者审核摘要」，不能冒充 Noyra 原话。来源对象必须属于当前主体。摘要更新不能回写或改变原始目标、项目、预测、睡眠和聊天。内部推理、理由、资源费用、供应商、私聊、记忆和凭证不进入匿名查询。睡眠原因只有显式公开的说明；不从 trigger_reason 推断。生命周期只读取 approved 状态元数据。

新增公开内容使用追加式 schema 93，保留旧数据和旧接口；不回填历史私有资料。公开摘要可撤回，但不增加聊天/记忆删除。客户端 no-store，切换或重读替换当前列表；后台隐藏时停止轮询，无声保留草稿不送入模型。

## 模块结果

实施后逐项填写实际验证与限制，不提前声明完成。

### P01 公开数据与接口基础

新增 schema 93 显式公开摘要和不可修改的修订元数据；新匿名 API 不调用私有投影。v1 字段/头保持原样；v2 独立头、no-store、2 MB 响应边界、每页最多 100、主体/筛选绑定游标；行为只读最新公开修订，交流只读 outgoing/public:*，生命周期只读状态枚举与时间，不读 reason。摘要 2000 条/16 MB 文字边界；没有证据/导出/聊天删除入口。

专项 33 项通过（74.14 秒），另 schema92→93 私有事件保留/零回填验证 1 项通过（2.99 秒）。固定 Ruff 检查通过，Mypy 四个相关文件通过。历史 schema76 标记重放最初暴露新 DDL 非幂等，已从根因改为 IF NOT EXISTS，原有 schema 验证保持有效，复验通过。HTTP 初始测试 fixture 缺少必要 settings，已修正并通过；没有通过放宽运行配置修复测试。当前完成的是数据与接口基础，P02/P03/P04 前端尚待交付。


### P02/P03 首页、生命周期与时间线

前端改为 v2 匿名档案，无管理员路径或共享伪导出代码。显示阶段进入时间、持续时间与获取时间；连接只表示成功响应，不把深度休眠称为离线。首页每30秒独立更新，历史列表不轮询重绘，隐藏页面停止读取。时间线支持六周期、分类、状态、文字搜索、稳定游标和详情深链接，单屏最多200条，重读失败不继续展示旧正文。投稿草稿仍仅在内存。

Node 81项通过，含12种跨页迟到成功/失败、首页独立失败、固定分页时间窗、撤回重读、XSS和错误契约；Python公开数据/HTTP/v1等38项通过，静态前端15项复验通过。旧测试原先仅断言公开bundle里的管理员导出注释，已改为真实公开隔离断言，没有把注释当成功能。Playwright在本地隔离数据库验证首页与时间线，真实翻页20→32条，桌面1440与手机375截图，控制台零错误；其他尺寸及投稿端到端仍在P06/P07复审。P04结构详情和P05管理发布入口继续按顺序实施。


### P04 结构化公开摘要阅读

目标/项目显示审核进度与下一步、项目阶段与公开资源状态；预测显示概率/目标时间/结果且明确不是保证；研究显示不确定性和安全HTTPS参考；睡眠显示公开起止和时长。零进度/零概率不会当成缺失。没有新增私有域查询或自动发布。浏览器在375宽实际读取项目卡片和进度；复审发现严格CSP下内联进度样式不可用，改为原生progress和外部CSS。Node公开22项通过，新增恶意参考URL、隐私字段忽略、零值与时长测试。此模块只展示审核摘要，不属于暂缓的公开证据/证明模块。
