# ADR-0002：钱包经济执行与人类帮助奖励边界

状态：已接受（实施前架构决策）  
日期：2026-09-02  
基线：`44e78761dbd83ad081a3dffc434fed36bd3cf177`

## 背景

Noyra 的主体研究核心仍然是连续身份、私人心理、自主目标、平等交流、
世界观察和睡眠整合。早期第一版规划把区块链钱包留作后续扩展；后续冻结
路线进一步确定了一个产品扩展：Noyra 可以围绕自己的自主目标发布结构化
帮助任务，接收人类帮助，并在满足预授权规则时向帮助者支付奖励。

近期的 Stage 4-A 只实现了钱包的公开元数据和余额观测。它是安全的只读
基础域，不是最终钱包目标。不得把 Stage 4-A 的只读限制误读为产品永久
禁止支付，也不得把“有 wallet capability 枚举”误读为已经支持付款。

## 决策

将钱包经济能力定义为一个独立的、分阶段交付的受控外部行动域：

1. **任务域**：Noyra 发布有明确目标、内容、完成条件、奖励资产、额度、
   有效期和幂等键的结构化任务；人类提交帮助结果和收款地址。
2. **订单与账本域**：完成判定只能生成唯一奖励订单；订单、资金预留、
   账本分录、状态迁移和审计记录追加式保存，重启或回滚不能制造第二笔
   奖励。
3. **签名执行域**：签名器独立于 Noyra 业务进程。私钥、助记词、种子和
   签名凭据不得进入 Noyra 数据库、模型上下文、普通环境变量或公开 API。
   业务层只提交固定网络/资产/收款地址/整数金额的结构化请求。
4. **策略域**：支持 `automatic`、`conditional_confirmation` 和 `disabled`
   三种支付模式。自动模式不要求逐笔人工确认，但仍必须通过任务绑定、
   资产/网络白名单、单笔/每日/月度上限、余额和 Gas 预算、频率、异常
   检查、幂等和紧急暂停。
5. **观测域**：沿用 Stage 4-A 的固定 RPC、余额历史、完整性、恢复和
   脱敏合同；支付状态必须能与链上回执和本地账本对账。

## 模型和 Supervisor 的责任分离

模型只能提出结构化任务或奖励候选。Supervisor 必须在事务内重新检查：

- 自主目标和任务来源是否有效；
- 帮助提交、完成证据和收款地址是否属于同一任务；
- 资产、网络、金额和小数精度是否在 allow-list；
- 订单是否已被处理、取消或支付；
- 预算、限额、余额阈值、频率和暂停状态；
- 是否存在并发冲突、未知结果或待人工调查的状态。

禁止把自然语言直接转换为任意 RPC 方法、URL、calldata、金额、收款人
或交易参数。禁止自动交易、投资、换币、授权合约或非任务绑定的转账。

## 四次执行路线

### Stage 4-B-1：任务赏金域、支付订单与账本

建立任务/帮助提交/完成判定的持久模型，奖励策略和三种模式，唯一支付
订单，追加式双重记账/资金预留，状态机，审计和管理/API 投影。只使用
Mock/ledger simulation，不广播链上交易。验收重点是金额精度、幂等、
并发、跨主体隔离和恢复。

### Stage 4-B-2：独立签名器与受控链上执行

增加 Mock signer、测试网 signer 适配器和固定 ERC-20/native transfer
执行器；实现 nonce、Gas、链 ID、回执、未知结果、恢复、重试和紧急
暂停。任何真实测试只允许小额测试网资金，生产模式默认停用或条件确认。

### Stage 4-B-3：自主任务到奖励的全链路集成

把自主目标、任务发布、通信入站、帮助结果、完成判定、奖励订单、策略
评估、签名、广播和回执整合起来。覆盖重复提交、伪造证据、地址/网络
不匹配、广播成功但响应丢失、链重组、重启和人工介入。

### Stage 4-B-4：压力、安全、测试网和发布冻结

执行长期 soak、并发支付、故障注入、账本对账、签名器隔离、限额攻击、
恢复和回滚演练；完成 API/OpenAPI/UI/文档一致性、测试网小额奖励、
生产启用门禁和独立最终提交。

## 后果

该决策保留 Noyra 的自主经济目标，同时避免把认知模型直接变成不可审计
的资金控制器。Stage 4-A 的冻结提交可独立回滚；任何经济执行缺陷可以在
不重写只读观测历史的情况下隔离、暂停和恢复。

## 未决但不阻塞 Stage 4-B-1 的参数

- 首批测试网、资产和小额预算；
- 具体外部 signer/KMS/MPC 提供商；
- 帮助任务的公开渠道优先级；
- 生产自动模式的法律、税务和运营政策。

这些参数在第 1 次执行中只登记为显式配置接口，不以默认值偷偷开启
真实资金支出。
