# Cognitive result categories

Cycle results use one conservative category function for operational waiting,
no change, failure and unverified output. Waiting for reconciliation, a planner,
a due target, a concurrent worker, changed context or budget is not a claim of
provider failure or an unknown paid call. Complete suffixes are matched; an
arbitrary string containing `failed` is not classified as a failed operation.

Metacognitive evaluation still prefers the matching durable episode/run and its
actual token usage. A success-like string without such evidence cannot earn
productive credit. The existing outcome vocabulary and historical profiles are
unchanged: `stagnant` means no verified progress this turn, including operational
waiting; `failed` represents an observed failure/rejection, and `unknown` remains
an unverified evaluation. The detailed original result is retained as its
rationale, so a wait can be distinguished from an unsuccessful attempt.

This local evaluation never settles model calls, releases reservations, retries
unknown work, changes budgets or rewrites previous strategy outcomes. Provider
unknown outcomes remain governed by their ledger and reconciliation protocol.
