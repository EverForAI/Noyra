# Help-request language boundaries

Autonomous relationship help retains its deterministic local check against
recipient-directed obligations, guilt pressure and explicit threats. Ordinary
terms such as `mustard`, first-person `I must verify`, urgency descriptions and
`otherwise` followed by an alternative do not establish coercion. Negative
assurances such as `you do not owe me` are not direct demands.

The check normalizes compatibility characters, case, whitespace and typographic
apostrophes before evaluating complete word/phrase patterns. It recognizes
explicit obligations to the recipient, guilt conditionals and sender threats;
English and a small set of direct Chinese coercion signals are covered by a
frozen positive/negative regression set. This is a bounded rule check, not a
claim to solve every quotation, language or possible paraphrase.

The social validation boundary uses this check only for help-request content.
Existing relationship ownership, identity consistency, contact refusal/cooldown,
evidence, affect, model budget and structured validation remain in force. A
rejected request cannot create an outgoing message. A benign request can proceed
under the existing autonomous route without new manual approval or default
recipient allowlists. No historical rejected proposal or delivery is replayed.
