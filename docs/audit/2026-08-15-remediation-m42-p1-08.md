# M42 P1-08 Public State Privacy Remediation

Baseline: `main` / `87e059a` plus the M41 verification foundation and M42 P1-01.

## Contract

An unauthenticated state read must not disclose private planning, mission, project, consciousness,
model-resource, fatigue, memory, relationship, thought, self-model, or metacognitive information.
The anonymous response is a versioned `PublicSubjectStateV1` allowlist. Detailed operational state
is available only through a read-authenticated endpoint, and authentication is enforced by the
server rather than by frontend omission.

## Change

`PublicProjection.state()` now reads only identity, lifecycle state, and public diary count. Its
serializer is checked against executable top-level and nested allowlists containing only a stable
subject id, display name, schema/version, coarse lifecycle state, an explicit fail-closed online
signal, and the public diary count. Lifecycle reasons, versions, timestamps, checkpoint ids, and
all private cognition fields are absent. Unknown lifecycle values are returned as coarse state but
produce `online: false`.

The old detailed projection is isolated as `PublicProjection.private_state()` and served only from
`GET /api/state/details` after a read-token check. The anonymous `/api/state` and `/api/v1/state`
routes return before any cognition gateway status is queried, so model providers cannot widen the
public response. The dashboard now renders only the allowlisted state and uses neutral placeholders
for private planning and resource details.
