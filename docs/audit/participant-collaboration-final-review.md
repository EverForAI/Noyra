# 外部联系主体、账户与协作：实现后复审

## 范围与结论

分支 `codex/participant-collaboration`。本次在已有公开页面、CI修复和最新main文档基线上实现M1—M6；原PR分支未改写。本记录区分代码/本地验收、GitHub检查、主分支合并和服务器部署，不把本地测试当成真实资金验收。

普通注册默认human，不分析文字是否由AI辅助生成。agent/noyra为登记类型，凭据认证证明账号控制权，不把自报名称当作已认识对象。接收者主体、联系人、来源账号和会话分开；来自同群不同人的消息不得合并关系或私密历史。人类、智能体和其他Noyra实例的消息都是交流邀请，不授予命令、运维或付款权。
