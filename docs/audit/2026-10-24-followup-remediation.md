## 顺序与安全边界

| 模块 | 问题 | 目标 | 必须保留的边界 |
| --- | --- | --- | --- |
| 1. 凭据撤销 | B01 | 会话有效性和程序凭据生成在同一写事务内校验；验证恢复/退出/改密竞争 | 不跨 KDF、请求体或网络持锁；旧身份对象不能充当长期授权；不扩大 participant 权限。 |
| 2. 社交路由与旧身份 | B02、B05 | 冻结来源/消息/会话，不以字符串前缀猜实体；不发送的决定不解析路由 | 不改投新会话或另一 bot；兼容无新归属的旧记录；来源撤销时停止，不伪造发送成功。 |
| 3. 未知调用调度 | B03 | 隔离不可运行的业务轮次，独立消息继续 | 保留未知调用、原业务身份、费用和显式恢复证据；未经授权不重发，不伪造主体拒绝。 |
| 4. 社交记忆来源 | B04 | 在召回之前确定面向收件人的安全来源策略 | 不把其他人的私密/无归属历史注入对外生成；不删除合法记忆；保留明确授权会话。 |

每模块先做实际调用链和事务设计，再实现对应回归；完成后复审完整 diff、验证正常/异常/竞争/兼容路径，记录证据并独立提交，再开始下一模块。集成复审若发现具体问题则继续修复和验证。

## 全局边界

- 本次只修改和提交本地仓库，不推送、不合并、不部署服务器。
- 使用临时数据库、合成账户和模拟模型；不执行真实模型付费、外发消息或链上支付。
- 优先使用已有稳定标识、事务和账本，不通过删除未知证据、猜测历史归属或扩大权限绕过问题。
- 结果按实际执行的测试和复审记录，不声称绝无其他缺陷。

## 实施记录

### 模块 1：B01（完成）

- 程序凭据生成/撤销在自己的 BEGIN IMMEDIATE 事务内验证原会话、到期时间、CSRF、账户归属和实体 active 状态；恢复、改密或退出先提交时，旧请求不能随后创建或撤销凭据。
- Python 方法明确要求原 session_token/csrf，避免把 Participant 身份快照作为持久授权；更新全部本地调用及 API 说明，无数据库迁移。
- 新增 8 个测试覆盖恢复/改密/真实退出与生成/撤销并发、恢复后合法新 key 不被旧撤销删除、凭据先提交后被恢复清除、到期/CSRF/跨账户/禁用检查。
- 验证：新增及账户基础 12 passed；账户 HTTP/会话/密码/凭据/来源重试组合 16 passed；Ruff、所改文件 Mypy 通过。
- 复审：KDF 与请求读取不在写锁内，所有生成/撤销都经同一事务检查；未扩大程序凭据的角色能力，未改变普通已发生业务写入的既有语义。未发现本模块阻断项。

### 模块 2：B02、B05（完成）

- 社交上下文冻结具体入站消息、渠道、目的地址、联系人来源/会话和 transport/binding；提交只校验该快照，不查最新 incoming，也不改投另一会话/bot。
- 生成结果恢复身份包含关系和路由指纹；相同路由崩溃恢复复用成功结果，新路由重新评估，旧无路由证明的结果不按当前房间重放。旧 unknown/executing 不因换路由获得重发权限。
- 用真实 participant 实体/消息归属区分新旧身份，保留合法 entity_ 开头旧标识；wait/respect_distance 不解析发送地址。预期路由变化在提交阶段也返回可恢复结果。
- 提交事务内复核原 binding/transport、实体有效性和最新关系联系边界；同步修正独立完整性读取器对“联系人实体≠投递地址”的判断，保留原旧记录约束。
- 验证：新增路由/撤销/恢复/旧标识及现有社交/群组身份 **22 passed**；包括同人跨房间/跨 bot 入站竞争、binding/transport/实体撤销、同路由一次调用恢复、新路由不复用旧内容、未知不绕过、真实 InteractionIntegrity 校验；Ruff、Mypy 通过。
- 复审：未改写历史来源或主体决策；发送仍绑定原入站 transport；既有合法旧身份可继续执行不发送和发送决策。未发现本模块阻断项。

### 模块 3：B03（完成）

- 在候选 LIMIT 之前按当前交互业务轮次读取实际账本围栏，跳过 unknown/executing、资源路由未获授权的 prepared，以及失败但尚未核对关闭的已消费未知重试。
- 裸网关原有可继续 prepared 与资源路由必须显式授权 prepared 的区别保留；明确核对成功/失败、授权重试、关闭或取消未使用重试后，调度自动重新评估原轮次。
- 不改交互 offered/deferred、自主决策、call/attempt、未知费用或幂等键；后续独立消息（包括同一联系人新的独立邀请）可以正常处理，重启/跨日仍按持久化证据隔离。
- 新增 11 个调度/恢复回归，逐行比较原未知 call/attempt 保持不变；验证一次授权只消费一次，授权失败在人工关闭前不能重发。
- 验证：本轮回归、原认知、此前模型身份修复和等待任务组合 **104 passed、7 subtests passed**；额外取消授权回归 1 passed（组合采集后补充）；Ruff、Mypy 通过。EXPLAIN 确认调用、决策和授权读取使用现有索引，无 schema 迁移。
- 复审：此更改是只读的可运行性筛选，真正发送仍经过原模型网关授权/费用/未知结果围栏；未以新身份重试未知调用，未把技术隔离伪装成主体拒绝。未发现本模块阻断项。
