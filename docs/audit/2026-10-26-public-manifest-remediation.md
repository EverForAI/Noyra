## 工具模块复审

工具先读取提交或暂存区的 object ID，再以 `git cat-file --batch` 读取不可变 blob。生成过程不读取工作区源码，不自动暂存，不自动允许新文件；二进制不解码，文本不手工归一化。

路径审核拒绝缺失、重复、大小写/目录冲突、未审核新增、符号链接、子模块及跨平台危险路径。允许清单与带理由排除清单必须完整分割 Git 跟踪路径。校验表自身不自引用，其内容由 Git 及包级签名固定。

源码 ZIP 的条目顺序、时间及模式固定；导出只写允许的 Git 内容，拒绝覆盖已有文件，并复核实际 ZIP 的路径集合、重复、模式、长度与原始字节。`.gitattributes` 导出转换不会改变包内内容。归档检查先限制预期大小，再读取并对照对应 Git blob。
