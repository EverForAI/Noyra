# R01 历史证据与旧库兼容验证：执行边界

日期：2026-10-25（北京时间）。基线：5f976f8e6f282d6ef74d4e457ea9d45c515e957b。

本轮授权仅为历史证据盘点、兼容方案和隔离验证，不实施 R01 产品修复，不连接服务器，不读取未经提供的生产数据库，不修改 src/deploy/scripts 或现有版本/验签/身份合同。独立分支 codex/audit-r01-compat-validation；结束前提交文档及验证用例，保持原候选、R06/R02/R04 和 R05 分支不变。

执行顺序：
1. 清点实际关系创建者、直接 SQL 读取者、事件/参与者不可变约束，以及导出/恢复/删除边界。
2. 用仓库固定哈希历史 fixture 只读统计，明确它们是否真的包含关系数据；不把空库迁移当作历史社会关系已验证。
3. 建立真实 InteractionStore/InteractionCognition 生成的现代数据，以及旧版地址键、泛化事件、缺失/跨主体/冲突来源、同名主体、agent/noyra 映射等反例；检查可关联证据是否真的能证明创建时归属。
4. 仅在临时副本验证“新增不可变 observed baseline”的可行性：不回写旧权重/修订、不将当前值称为已证明的原始身份；中断回滚、幂等、读写冲突、备份/恢复和导出合同缺口均单列。
5. 固定源代码运行回归，形成结果与待决策清单；不自动进入产品迁移实施。

验收底线：只读检查不得创建不存在的库、修改数据库或拉取归档私有内容；缺证据/超界不得自动判可信。公开汇报只含类别/计数及合成证据，不能输出私人消息、账号口令、密钥或生产关系名单。分类结果是风险线索，不是身份真实性认证。
