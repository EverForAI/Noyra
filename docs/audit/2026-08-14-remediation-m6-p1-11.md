# Noyra P1-11 修复复核

日期：2026-08-14  
范围：未认证的目标、项目和学习历史接口泄露私人计划。

## 修复内容

`/api/goals`、`/api/projects` 和 `/api/outcomes` 现在统一要求 `read` 角色。未认证
请求返回 401，不再因为服务错误绑定公网而泄露目标描述、项目验收标准、项目阶段或
学习历史。公开日记、已脱敏行为摘要和公开交流接口保持原有匿名可读边界。

桌面面板使用一次性输入的读取令牌加载三类私人视图，不保存令牌；未提供令牌时显示
空状态而不发起请求。

## 验证

* 服务测试覆盖未认证拒绝和 read token 成功读取；
* 前端仍可加载目标、项目和学习视图；
* 全量测试、静态检查、依赖审计和 Ubuntu/部署专项审计在提交前执行。
