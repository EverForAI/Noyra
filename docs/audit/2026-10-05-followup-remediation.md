- 由 root 从摘要已认证的暂存数据库读取并校验 genesis，生成 root 私有的逐任务 EnvironmentFile，覆盖主体 ID、genesis、target_id。钱包关闭模式显式覆盖旧钱包配置；本地钱包设置合并进同一 root 文件，不再由服务账户持有可修改的运行环境文件。生成和验证在停止旧服务之前完成，不导入源端任意环境/命令。
- 回滚恢复原 drop-in 及其引用的原环境文件。发现旧 target_id 的多行配置解析遗漏 MULTILINE，已修正，避免迁回原已迁入主体时错误地要求 target_id 为空。
- 新测试启动真实 NoyraService.from_env()/boot 并断言完整性通过和准入开放，覆盖普通/本地钱包完整加密传输、不同主体与 genesis 的目标切换、切换后就绪失败恢复、主动停用恢复、旧 target_id、非法 genesis 环境注入拒绝。操作系统服务调度和加密卷仍是夹具，不宣称真实 systemd 已验收。

- 验证：activation/binding/agent CLI 组合 **50 通过、1 Windows/POSIX 跳过**；受影响源码和测试 Ruff、严格 mypy 通过。新增夹具最初的缺失辅助函数和 Any 返回标注已修正；随后组合全部通过。最终 SHA 全量验证另行记录。


### 全量回归发现的错误合同修正

- Windows 全量回归和独立复现确认：B08–B10 新计数检查在不存在的主体上先抛出内部计数完整性错误，改变原 ModelLedger 的 SQLite 外键错误类型。非法写入一直拒绝，没有新增准入绕过；但原调用方错误合同需要保留。
- 修复：仅在计数不完整分支中查询主体是否存在；不存在维持 sqlite3.IntegrityError，已有主体缺失计数仍是内部 IntegrityError，不创建/补全计数、不放行工作。正常路径仍只查八个计数。
- 验证：既有未知主体拒绝测试，加上完整容量/并发/损坏/迁移/一万行查询成本组合 **10 通过**，Ruff/严格 mypy 通过。临时 Linux pytest-xdist 对 unittest memoryview 子测试的序列化错误属于测试工具兼容问题；已移除该插件，最终用独立进程分组运行原测试，避免改业务或删断言适配工具。


### 安装权限边界复审

- 真正以服务账户执行安装目录权限复现时发现，安装器创建的 root 管理迁移目录会被 at-rest 通用硬化逻辑当成服务账户目录 `chmod`，导致 required 模式启动失败。这不是迁移协议问题，而是部署权限合同冲突。
- 修复：at-rest 只对安装器认可的 root:noyra 迁移控制布局做专门、严格的结构/设备/所有权/模式校验；通用硬化遍历只纳入服务账户拥有的 `source`/`requests`，对 root 管理目录和可见控制文件只核对元数据，不修改其权限。备份保留 source 和 fences，排除机器本地的请求/状态队列与 root-only activation state；无法读取的 fence 明确使备份失败，绝不静默丢弃。任何额外目录、链接、错 owner/group/mode 或跨设备均拒绝。普通 root-owned 条目继续 fail-closed。
- 验证：WSL root 创建真实 root/service 目录后，以 uid/gid 65534 启动 required `NoyraService`、完成加密备份和恢复，读取 source/fence 且排除 root-only activation 状态，**1 通过**；owner、可写、state、额外项和 symlink 篡改 **5 通过**；at-rest 与权限边界组合 **46 通过、2 Windows ACL 跳过**。设备探测仅注入测试状态，其余访问、权限、服务启动和备份均真实。


- 部署权限后续检查：HTTP executor 的默认产物目录原为 root 管理目录下的 migration/outgoing，服务账户无法新建；改至已安装的 service-owned migration/source/outgoing。真实非 root 测试串联实际 SQLite 备份、recipient 加密产物、at-rest 复核、保留 fence 的加密备份及恢复，六项权限边界测试全部通过。此补强不更改 root 控制权限，也不把控制队列复制到恢复主体。

- 独立提交临时 checkout 为 0700，真实服务账户测试不能读取其中源码。测试夹具现复制同一份源码到单独的可读临时目录，仅测试目录放行，不放宽业务数据或仓库权限；再次运行权限边界六项通过。
