# 长期证据与容量边界

健康聚合、搜索限速记录和维护结果按已配置周期删除；冷模型 I/O 按 runtime days 压缩，压缩扫描有持久游标。不会加入查询缓存，也不新增每次 API 请求的原始日志。

模型账本、调用尝试、研究结果、行动推理和行为日志是必要证据：幂等重试、当日预算、行为版本、认知来源、资金及迁移恢复会引用它们。现有关系合同不允许仅按日期删除；备份或导出成功本身也不能证明删除后在线引用仍然成立。

`NOYRA_EVIDENCE_MAX_ROWS_PER_TABLE` 默认 250000，支持 1 至 10000000。管理台的数据保留页显示上限及计数。达到上限后暂停新的认知周期，模型账本和行动准备的事务边界也检查上限；已有动作完成、已有模型尝试记账、重复请求查询、付款恢复、备份及导出不受此开关阻断。行为和研究行分别由已经被限额的动作/模型调用产生，因此它们同样有有限来源。

不能用删除必要证据来恢复容量。应先做加密备份和验证恢复，再按实际磁盘容量合理调大上限、增加数据盘容量或迁移到更大设备。行数上限与现有数据字节配额、磁盘余量和趋势预测同时生效，行数上限不能替代字节检查。已有超过上限的数据保留原样，停止新增工作，不删除或重写历史。

现阶段可执行生命周期合同如下，管理接口也返回同一份逐表合同：

| 表 | 保留原因 | 新增边界 | 历史恢复 |
| --- | --- | --- | --- |
| model_calls | 永久请求幂等、预算、认知来源 | 新调用及其研究/推理来源达到上限即拒绝 | 认证加密备份，runtime 导出 |
| model_attempts | 预留/实际调用计费、unknown 恢复 | 新尝试达到上限即拒绝 | 认证加密备份，runtime 导出 |
| actions | 永久动作幂等、外部副作用恢复 | 新动作及其行为记录达到上限即拒绝 | 认证加密备份，runtime 导出 |
| behavior_logs | 每个终态动作一条记录与版本来源 | 被有界 actions 来源约束 | 认证加密备份，runtime 导出 |
| research_search_runs | 项目/认知来源；不可删除 | planner call 唯一索引及有界 model_calls 来源 | 认证加密备份，runtime 导出 |
| action_deliberation_runs | 不可删除的推理结果与永久结果身份 | 固定 call 幂等键及有界 model_calls 来源 | 认证加密备份，runtime 导出 |

到达边界不会停止生命周期维护、已有付款的完成或回执恢复，只停止新增认知工作；已启动工作的证据允许补齐。由于已有来源同样有界，这不是另一条无限写入通道。历史超过上限时计数显示为下界并停止新增，不假装旧库只有上限数量的记录。

这套合同关闭的是“不受限制地新增必要证据”的容量风险；代价是达到容量后需要部署者扩容。它没有实现按年龄删除必要历史、外部在线查询或无限期运行在固定空间中的能力。后者必须重新设计跨层引用和永久幂等协议，不能通过清理开关假装已经具备。
