# 长期证据与容量边界

健康聚合、搜索限速记录和维护结果按已配置周期删除；冷模型 I/O 按 runtime days 压缩，压缩扫描有持久游标。不会加入查询缓存，也不新增每次 API 请求的原始日志。

模型账本、调用尝试、研究结果、行动推理和行为日志是必要证据：幂等重试、当日预算、行为版本、认知来源、资金及迁移恢复会引用它们。现有关系合同不允许仅按日期删除；备份或导出成功本身也不能证明删除后在线引用仍然成立。

`NOYRA_EVIDENCE_MAX_ROWS_PER_TABLE` 默认 250000，支持 1 至 10000000。管理台的数据保留页显示上限及计数。达到上限后暂停新的认知周期，模型账本和行动准备的事务边界也检查上限；已有动作完成、已有模型尝试记账、重复请求查询、付款恢复、备份及导出不受此开关阻断。行为和研究行分别由已经被限额的动作/模型调用产生，因此它们同样有有限来源。

不能用删除必要证据来恢复容量。应先做加密备份和验证恢复，再按实际磁盘容量合理调大上限、增加数据盘容量或迁移到更大设备。行数上限与现有数据字节配额、磁盘余量和趋势预测同时生效，行数上限不能替代字节检查。已有超过上限的数据保留原样，停止新增工作，不删除或重写历史。

完整的外部历史分层还需要一个支持在线历史查询、跨层外键及幂等证明的归档协议。这次提供的是有界容量准入，不声称已经提供无损删除所有历史行的能力。
