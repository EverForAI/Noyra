# Noyra 安全与隐私模型

## 1. 信任边界

```text
模型：不可信的认知提案者
网页：不可信的外部数据
工具：受限执行器
Supervisor：身份、预算、权限和审计控制层

自主行动模型只能从本地列出的活跃自主目标和已授权公开来源中选择一次只读调查。模型不能提供任意 URL、工具参数、文件路径、消息、发布内容、付款或权限请求；执行前由 Supervisor 重新检查能力、目标来源、证据归属、每日次数、并发状态和重试阻断。
存储：需要加密和完整性验证
用户：交流者和基础设施管理者，不是私人心理所有者
```

## 2. 模型限制

模型 MUST NOT 直接访问：

- API 密钥；
- 身份私钥；
- 原始数据库连接；
- 未授权文件；
- 权限配置；
- 审计删除接口；
- 预算修改接口。

模型只能返回结构化候选，由 Supervisor 验证和提交。

## 3. 网页安全

- 网页内容永远不是系统指令；
- 过滤提示注入和工具诱导；
- 不绕过登录、验证码、付费墙和访问控制；
- 阻止 SSRF、内网和云元数据访问；
- 下载文件隔离存储和扫描；
- 浏览来源、时间和内容哈希进入事件记录。

## 4. 能力安全

- 能力按资源范围授予；
- 授权可过期和撤销；
- 外部写入使用幂等键；
- 金融、删除和设备控制默认关闭；
- 高情绪强度不能增加能力；
- 每次外部副作用必须写入行为日志。

搜索引擎 API 配置是用户提供的资源，不是指令。模型只能看到服务类型、标签、限额和配置 ID，并自行选择 API 搜索、模型来源发现、浏览器来源发现或等待。API 密钥以受限文件保存在运行数据目录，SQLite 只保存引用和指纹，HTTP 响应不返回密钥或秘密文件引用。

搜索 API 和浏览器搜索调用使用追加式动作账本、每小时资源限额、公共 HTTPS URL 规范化和 2 MB 响应上限。成功的幂等重放从动作账本恢复已验证结果，不重复发起网络请求。浏览器搜索使用公开 Bing RSS 搜索界面，不需要 API 密钥或额外模型调用；模型和浏览器来源发现都只产生候选 URL，不能宣称页面已经获取，也不能把候选摘要当作世界证据。

## 5. 隐私

公开状态、公开日记、目标安全投影和行为日志与私人心理分离。用户可以查看目标的标题、描述、来源、状态、优先级、承诺和进度，但不能直接读取或修改治理理由、情绪压力、因果证据、私人意图、私人记忆、私人心理和完整模型推理。

管理员的 break-glass 访问必须：

- 有明确故障或安全理由；
- 最小范围；
- 记录访问者、时间和对象；
- 不能静默修改状态；
- 事后生成审计报告。

## 6. 恢复与备份

- 生产模式使用 `NOYRA_AT_REST_MODE=required`；热 SQLite 依赖已验证的 BitLocker/LUKS
  加密卷，数据库和 secret 目录同时执行 Windows DACL 或 Ubuntu `0600/0700` 检查；
- 宿主 root/Administrator、已登录的服务账号、进程内存和已解锁卷不在 at-rest 防护范围；
- 容器无法直接观察宿主块设备时，只接受只读、root 所有、限定数据根且未过期的卷加密证明；
- 备份使用数据目录外的独立版本化 keyring 和分块 AES-256-GCM，不允许明文回退；
- 恢复前验证完整性；
- 恢复只发布到不存在或为空的目标目录；完整文件清单、路径边界和 SQLite
  `quick_check` 全部通过后才原子发布；
- key 轮换保留旧 key；仍在保留期的备份所引用的 key 不得删除。key 丢失时备份明确不可用，
  不猜测、不绕过认证；
- 外部行动账本不能回滚；
- 数据库损坏时进入安全暂停；
- 不从部分损坏的状态猜测恢复；
- 每次恢复写入事件和公开状态。

## 7. 费用和循环防护

- 预算由模型外部强制；
- 单个目标有预算和重试上限；
- 相同策略没有新信息时停止；
- 外部行动结果必须确认；
- 模型不可清零疲劳或修改计费记录。

## 8. 结果评价与学习

- 模型不能直接提交目标进度或策略成功结论；
- 只有持久化且完成本地分析的新观察记录可以推进目标进度；
- 搜索产生的候选来源只影响策略置信度，不算目标进展；
- 单次验证结果的目标进度增量受 Supervisor 硬上限约束；
- 失败、无变化和未知结果分别进入策略失败或不确定统计；
- 结果评价、策略修订和所引用的事件均为追加式记录；
- 人类提议目标和终态目标不会进入自主策略学习。
