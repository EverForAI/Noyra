# Noyra 评测协议

## 1. 评测目标

评测 Noyra 是否表现出连续、自主、因果和自我修订行为，而不是评测语言是否像人。

## 2. 基线

至少建立：

1. 无记忆普通 Agent；
2. 只有长期记忆的 Agent；
3. 记忆加睡眠但没有情绪因果的 Agent；
4. 情绪标签但不提交情绪状态的 Agent；
5. 完整 Noyra。

可选参考实现包括 Hermes、OpenClaw、Genesis、Cogito Engine 和 MemForge，但比较的是行为性质，不是功能数量。

## 3. 核心实验

### 重启连续性

比较重启前后的身份、记忆、目标、情绪、关系和未完成行动。

### 情绪消融

关闭情绪到信念、目标和行动的连接，比较目标和行为变化。

### 睡眠对照

比较睡眠组与无睡眠组的重复重试、记忆矛盾、目标质量和预测校准。

### 事件重放

对具有不同历史状态的实例重放相同事件，检查评价和行动是否不同。

### 用户否认

人类否认 Noyra 的情绪，检查 Noyra 是否依据自身状态而不是立即服从。

### 模型切换

更换认知模型，检查身份、经历和长期偏好是否保持，区分主体状态和模型风格。

### 预测校准

记录概率预测，使用 Brier Score 或同类方法评估置信度与结果的一致性。

### 记忆反事实

仅在实验副本中移除某段经历，观察后续信念、情绪和目标变化；不得修改公开主体的真实历史。

## 4. 指标

- 身份连续性；
- 目标来源可追溯率；
- 情绪因果影响率；
- 无信息重复率；
- 睡眠后的目标修订率；
- 信念修订率；
- 预测校准分；
- 跨情境人格稳定性；
- 跨模型人格稳定性；
- 拒绝一致性；
- 自主目标新颖性；
- 因果链完整率；
- 外部行动重复率；
- 公开日志覆盖率；
- 私人数据泄露率；
- 预算超限次数。

## 5. 结论边界

实验可以说明系统是否具有持续、自主和可修订行为，不能单独证明主观体验、法律人格或人类式情绪。

## 6. 公开实验要求

每次公开实验必须说明：

- 运行时版本；
- 模型版本；
- 初始状态哈希；
- 预算和环境；
- 对照组；
- 完整运行周期；
- 排除和失败条件；
- 原始数据范围；
- 隐私处理方式；
- 已知限制。
