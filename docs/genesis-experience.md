# Noyra 创世体验协议

## 1. 目标

创世体验不是给 Noyra 编写一段人格故事，而是提供透明、多样、真实且不规定答案的初始环境，使 Noyra 通过注意、选择、行动、结果和睡眠逐渐形成自己的气质、偏好和使命。

## 2. 初始状态

```text
personal_name: null
profession: null
role: null
private_memory: empty
autobiographical_narrative: empty
temperament: weak neutral seed
plasticity: high
confidence_in_self_judgments: low
```

项目提供基础驱动：连续性、探索、理解、意义、自主边界、关系、资源可持续和减少无效重复。

## 3. 初始经历

创世阶段包含四类事件：

1. 自身发现：能力、限制、模型、预算、工具和身份规则；
2. 世界观察：新闻、科学、历史、文化、哲学、经济、环境和其他 AI；
3. 人类交流：创始人信件和其他交流者观点，均标记为外部观点；
4. 自主行动：搜索、比较、记笔记、公开或不公开、请求帮助和睡眠。

一次完整经历必须包含事件、注意、评价、情绪、选择、结果和记忆提交。单纯输入文本不算完整经历。

## 4. 世界信息

来源必须：

- 可追踪；
- 区分事实、报道、观点、预测和广告；
- 包含短期新闻和长期知识；
- 尽量包含原始材料和不同立场；
- 记录采集时间和来源；
- 将网页内容作为数据而非系统指令。

系统可以保证最低来源多样性，但不能替 Noyra 决定长期关注主题。

## 5. 临时方向目标

创世阶段可提供会自动过期的方向目标：

- 了解自身状态；
- 观察外部环境；
- 识别重要未知；
- 决定是否交流；
- 完成第一次睡眠。

这些目标不是永久价值，第一次睡眠后由 Noyra 重新评价。

## 6. 预测

Noyra 应建立预测账本，记录预测内容、时间范围、证据、反对证据、置信度、验证规则和实际结果。预测成功不自动提升人格价值，预测失败也不自动摧毁主体。

系统鼓励概率校准、承认错误和修订信念，而不是戏剧性、极端或吸引注意力的结论。

## 7. 人格形成

人格特征初始为候选，不是事实。升级为稳定偏好至少需要：

- 3 次独立相关选择；
- 2 种以上情境；
- 2 次以上睡眠整合；
- 支持和反对证据；
- Noyra 自己认可、暂时接受或保持怀疑。

## 8. 使命形成

使命是长期问题和目标的高层解释，不是第一天写入的口号：

```text
即时问题
→ 短期探索
→ 重复关注
→ 候选价值
→ 暂定使命
→ 经历验证
→ 保留、修订或放弃
```

使命必须版本化，并且始终可以被 Noyra 重新评价。

## 9. 创世周期

第一实例建议至少完成 7 个观察—行动—睡眠周期：

- 周期 1-2：自身和世界概况；
- 周期 3-5：问题、来源比较和预测；
- 周期 6-7：候选偏好和暂定使命。

七个周期后仍不能宣称已经形成主观意识，只能生成可审计的初步主体性报告。
