# 第 2 步：公开文件与 Git 历史安全审查

日期：2026-09-06。项目及拟建仓库：Noyra / EverForAI/Noyra。
公开署名：Jaxon Grey。审查起点：`158d73aab6fa35f1712f3c217119ea963012a05c`。

## 决定

本轮允许进入下一步验证的对象是**经本次文档脱敏的白名单源码快照**，不是整个开发目录，
也不是原开发分支及其父提交历史。没有上传代码、创建远端、修改可见性或创建版本标签。
原开发历史与运行数据保留在本机，没有重写、删除或轮换现有凭证。

未确认真实凭证进入当前受跟踪源码或已扫描的 Git 对象。该结论是限定工具与人工复核结果，
不是所有秘密、私人文本或未见数据都不存在的保证。发现了旧个人路径、历史元数据和本地
运行材料的公开边界问题，详见下表。

## 压缩夹具结论

5 个 `tests/fixtures/historical/schema-v*.sqlite3.gz` 的压缩及解压哈希均与既有 manifest 一致。
每库只有一个合成身份、一条 `m41_historical_anchor` 事件和 schema 元数据；v31 另含空 FTS
内部索引元数据。所有其他业务表为空，无 SQLite freelist 页，integrity_check 为 `ok`。
生成日期字段为固定合成值，核对生成脚本与逐行数据，不只因目录名叫 fixtures 就判定安全。
它们是迁移测试必需品，列入公开白名单；其他数据库、压缩包不获同类豁免。

夹具 `source_commit` 仍记录内部开发来源。源码快照首发后这些旧 SHA 不一定在公开仓库可访问；
普通测试使用已提交夹具，无须旧历史。重新生成历史夹具需要内部历史或后续单独审核的生成输入，
不得为使旧链接可用而附带整个未获公开许可的开发仓库。

## 仍阻断正式公开的事项

1. 最终公开提交的验证尚未执行；本次只完成公开内容安全准备。
2. GitHub 私密漏洞报告入口未启用核验；账号登录、仓库创建、真实 URL 可见性尚未检查。
3. 用户需要确认本清单及源码快照首发路径；未来公开提交邮箱须从账号核验，不能杜撰。
4. 既有 release workflow 对 `v*` 标签走生产发布门；预览发布路径未拆分前不推送版本标签。

搜索和扫描不能从机制上证明没有任意未知私密内容，原始对象扫描亦不覆盖工作区外的私人仓库、
主机凭据或其他运行数据。本轮不接触那些来源，也不将它们纳入允许公开范围。
