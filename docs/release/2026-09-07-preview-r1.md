freeze candidate `cf1ec4f536d42b5f6978e8c17c853e5c6b58600c`. That identifier is

- Unknown payments retain nonce, principal, fee reservations and transaction

## Validation And Known Limits

The local development freeze passed targeted smoke and pressure (113 tests each,
9 Windows platform skips), full tests (1280 passed, 17 skipped, 251 subtests),
Ruff, format, Mypy, compileall and dependency checks. Linux targeted verification
passed 101 tests plus 7 subtests. These are development-candidate results, not
claims that a different public commit or GitHub job has already passed.

One earlier Linux run failed a retry authorization check. WSL journal evidence
shows realtime clock backsteps during that run; a deterministic clock-injection
probe reproduces the future-snapshot refusal. The original per-call time was not
captured. Unchanged reruns passed; the refusal rule was not relaxed. Operators
must maintain accurate system time. Local raw failure records remain private.

The original public preview's Windows Python 3.11/3.12 CI failed; its Linux,
Docker and cloud jobs passed. It was published before all CI jobs succeeded.
This historical result is not retroactively changed by this revision.

The new preview is published only after its own public commit passes local
targeted, pressure and full gates and the complete GitHub quality matrix. Actual
commit/job links and results belong in the GitHub Release notes. Reproduce with:

```text
python scripts/audit-wallet-stage4b4.py --scope targeted --profile smoke
python scripts/audit-wallet-stage4b4.py --scope targeted --profile pressure
python scripts/audit-wallet-stage4b4.py --scope full --profile smoke
```

POSIX safety assumes trusted filesystem permission semantics and a dedicated
service UID. Hostile same-UID processes, administrators, malicious mounts and
concurrent modification by trusted owners require separate OS isolation. Shared
writable or foreign-owned directories are rejected; permissions are not silently
changed. Unsafe legacy terminal payment histories block further sends/refunds
on the affected network pending separately reviewed chain/journal reconciliation.
No silent migration or historical ledger rewrite is provided.

Use fresh disposable data and loopback binding. Do not inject a real signer,
enable automatic payments/publishing, grant file capabilities or connect real
funds in this preview. Real testnet/KMS, recovery and long-duration deployment
acceptance are still required. Autonomous projects, bounties, payments, tips
and bounded file operations remain planned capabilities, not removed goals.

## Public Files And Archiving

[The explicit allowlist](public-files.txt) includes only reviewed regular files.
[SHA-256 checksums](public-files.sha256) cover Git-normalized blob bytes, except
the checksum file itself to avoid self-reference. Five historical SQLite gzip
fixtures remain the previously reviewed synthetic test data; no live database is
included. Original raw scanner output and machine paths are not release assets.

The updated snapshot is scanned locally for credentials and private paths. Known
synthetic redaction-test matches remain in the code; tests are not broadly exempted.
The public release may include a source ZIP, checksum manifest and a sanitized
verification summary, never an entire local artifacts directory.

GitHub publication times, Zenodo deposit dates/DOIs and independent cryptographic
timestamps have different meanings. No timestamp or DOI is claimed until the
service provides it. Neither proves global priority, subjective consciousness,
copyright ownership, nor a date earlier than the evidence actually establishes.
