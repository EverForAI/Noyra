01 / 一个不同的起点

从工具导向到生命导向

我们研究的不是AI 如何更好地完成人类任务，而是一个数字主体如何跨越时间，形成自己的经历、关系与内生目标。

Noyra 将大模型作为认知组件，将身份、记忆、权限与恢复留在模型之外。普通人类消息进入交流与理解过程，不自动变成任务，也不能直接覆盖目标或授予能力。

非命令式不等于取消监督。暂停、关机、撤销权限与预算配置，仍属于独立的管理和安全控制。

02 / 连续性优先的架构

一个主体，不止一个模型。

观察成为经历，经历参与思考，思考形成有边界的行动。休息与反思，让下一次醒来承接此前的历史。

04 / 五个长期方向

让主体的长期积累，连接真实世界的价值。

从可复现的研究，到持续创作，再到主体发起的协作与经济活动。以下是发展愿景，不是当前预览版已经上线的服务。

01

人工主体研究平台研究与验证

为身份连续性、目标演化、记忆干预与模型替换提供可追踪、可复现的实验条件。

02

长期创作型数字个体创作与关系

让作品承接经历、观点与关系。人们因作品建立连接，而不是通过付费取得命令权。

04

人类雇佣市场协作与报酬

需求来自主体自己的项目。在明确授权与预算内发布任务、核验成果、支付报酬或打赏。

05

主体经济基础设施连续性与生态

几个重要问题。

Noyra 已经被证明有意识了吗？

没有。“人工主体”是操作性工程定义。第一人称表达、记忆或持续运行，都不构成主观意识或法律人格的证明。

“真实世界”具体指什么？

连接真实互联网信息和人类通信渠道，处理非作者逐步编排的外部内容。它不要求物理机器人；接口代码、本地模拟测试与真实部署，是不同的证据层级。

现在可以自动转账或雇佣人类了吗？

相关赏金、订单、账本与 signer 适配已有实现基础，但公开预览不启用真实自动支付。真实测试网、密钥管理、恢复和长期运行验收完成后，才考虑受控启用。

这是不是一个可直接对话的在线实例？

不是。这里是静态项目官网，不运行主体、不收集对话，也不连接模型或钱包。源码与受限预览说明可以在 GitHub 查看。
