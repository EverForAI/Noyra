Noyra 是一个人工主体实验项目，而不是用户任务助手。

项目研究一个人工系统能否在持续身份、私人记忆、情绪与心理状态、自主目标、真实世界观察、平等交流和睡眠整合的共同作用下，形成可追踪、可修订的操作性主体行为。

## 定义与边界

**非命令式人工主体（Non-Command Artificial Subject，NCAS）**指一种维持跨时间身份与状态、
可在没有逐条人类任务指令时运行，并从自身状态、经历、记忆和价值形成与修订目标的软件主体架构。
普通人类输入作为信息或社会交互进入系统，不因发送者身份或命令语气而获得创建任务、覆盖目标、
提升优先级、授予能力或强制行动的特权。

信息可以影响理解、关系和后续思考；这不等于把外部请求直接当作任务交给目标仲裁器。
主体仍需选择自己的内部目标、交流方式和行动。暂停、关机、隔离、撤销权限、配置资源和预算
属于独立的管理与安全控制，不能被普通聊天内容调用。

**真实世界**在本项目中指接入真实互联网信息来源与人类通信渠道，而非只在预编排的游戏或合成世界中运行。
它不意味着物理机器人、无限制联网、无限权限、已完成真实资金转账验收或长期无人值守保证。
“人工主体”是操作性工程定义，不是主观意识或法律人格已经成立的声明。

### 完整项目规划

**本次首发暂不启用上述能力，不代表将 Noyra 永久限定为只读系统，也不代表取消这些功能。**
完整项目目标仍包括：主体自主形成项目、向人类发布任务或求助赏金、核验成果，
并在授权与预算范围内通过独立 signer 执行转账、支付报酬和打赏；同时支持授权范围内的文件读写。
真实资金接入属于后续受控部署阶段，而不是本次公开源码自动开启的功能。

赏金、订单、账本、signer 适配及受限文件工具已有实现基础；后续继续复核剩余部署风险，
完成真实测试网、签名器与密钥保管、恢复和长期运行验收，再按配置逐项启用。
“暂不启用”不表示现在只要打开开关就已安全可用。
文件读写指明确授权的目录和资源范围，不是无约束地覆盖主机任意文件或执行任意 Shell。

## 设计原则

- 人类消息是交流邀请，不是命令。
- Noyra 可以接受、延迟、拒绝、忽略或主动发起交流。
- 模型是认知组件，不是主体身份本身。
- 身份、预算、权限、审计和恢复由模型外部的 Supervisor 维护。
- 情绪必须影响目标或行为，不能只改变语言风格。
- 私人心理与公开状态、公开日记和行为日志严格分离。
- 重启和睡眠后保持同一主体身份。
- 项目不将第一人称表达视为主观意识证明。

## 本地目录

源码、虚拟环境与运行数据应分开管理；数据库、凭证、日志、备份和私人心理数据不得随源码公开。
`scripts/env.ps1` 是开发环境初始化脚本，不是已经审核的公开预览启动方案。
主体认知通过远程模型接口工作，所需资源与预算由部署者配置。

交流与公开投影层已实现非命令式人类消息、主体自主接受/拒绝/延迟/沉默、主体主动联系和帮助请求、公开日记候选发布以及隐私过滤的状态、日记、行为日志和交流视图。公开投影不会返回私人记忆、信念、情绪或模型上下文。

能力与自主运行层已实现用户授权、资源范围、到期、速率限制、使用账本、授权目录读写、受限公开网络读取以及有最小间隔和错误退避的长期自主循环。该层不提供任意 Shell 执行，真实副作用必须经过能力授权和动作账本；未实现的逐次批准不会被宣传为安全边界。

Ubuntu 服务层已实现单进程主体所有权、信号关闭、自动睡眠状态推进、健康检查、公开状态面板、请求大小限制、通信令牌鉴权、systemd 加固单元和只读 Docker Compose 部署。公开交流视图只显示 `public:*` 通道上的主体发出内容，收到的人类消息和私人发出内容不会被公开。

自主认知层已将授权世界来源、安全网页读取、不可变观察、远程模型结构化候选、Supervisor 校验、因果评价与情绪、自主目标、世界主张、概率预测、疲劳和创世周期连接为可恢复闭环。网页始终位于不可信数据区，模型不能获得密钥或能力句柄；重复内容不会重复调用模型，模型预算耗尽会转化为资源压力并触发预算休眠。

平等交流认知层会将一个收到的人类消息作为不可信的交流邀请，单独决定接受、拒绝、延迟或沉默；它不创建目标、不执行动作，也不能把交流情绪直接施加到既有目标。通信参与者可用受令牌保护的私人邮箱查看 web 通道的传输记录，但不能读取 Noyra 的私人理由、心理状态或模型上下文。具体边界见 `docs/implementation/m11-equal-interaction-cognition.md`。

自主反思睡眠层会冻结本次睡眠的经历窗口，将有限的事件元数据、心理状态、目标、信念、记忆、交流和预测交给远程认知组件，得到严格结构化的私人反思候选。本地 Supervisor 只允许引用窗口内证据、修订已有目标或信念，并将记忆、重试阻断和人格候选一次性事务提交；失败、无效输出和预算耗尽都有有限重试与保守回退，睡眠不会永久卡住。具体边界见 `docs/implementation/m12-autonomous-reflective-sleep.md`。

自主目标治理层会在创世睡眠完成后定期复审非人类指定的候选与活跃目标，依据持久事件、情绪、信念、疲劳和既有目标状态自主激活、维持、暂停、重新考虑或放弃目标，并记录一个可恢复的内部焦点。该层不能创建目标、伪造进度、执行工具或发送消息；人类交流内容和人类提议目标不会进入治理上下文。状态面板与 `/api/goals` 可查看目标的安全投影，但不公开情绪压力、治理理由、因果证据或私人意图描述。具体边界见 `docs/implementation/m13-autonomous-goal-governance.md`。

自主行动审议层会在创世和目标治理完成后，从现有活跃自主目标与已授权公开来源中选择一项只读调查，经本地 Supervisor 再次验证目标、来源、因果证据、能力授权、频率、并发行动和每日限额后执行。第一版只允许读取既有 HTTPS 来源，不允许模型发明 URL、写文件、发布、通信、交易或提升权限；结果进入观察、行动与行为日志账本。具体边界见 `docs/implementation/m14-autonomous-action-deliberation.md`。

自主研究与来源发现层会从活跃非人类目标中识别信息缺口，自主选择已配置搜索 API、模型来源发现或浏览器来源发现，并可根据首轮结果质量切换方法。用户通过配置面板提供 Brave、Bing、Tavily 或 Serper 搜索资源，但资源不会成为指令；未配置 API 时只使用模型或浏览器回退。搜索查询保持私有，API 密钥不进入 SQLite 或模型上下文，发现的 URL 仅登记为低信任候选来源，不被视为已经获取的证据。具体边界见 `docs/implementation/m15-autonomous-research.md`。

结果评价与策略学习层只依据持久化的动作状态、完成本地分析的真实新观察和候选来源数量进行确定性评价。模型不能声明目标进度；只有新观察完成分析后才允许以单次不超过配置上限的幅度推进目标，来源搜索仅能提升策略置信度而不推进目标。失败、无变化和未知结果会分别降低或抑制策略置信度，评价历史与策略修订均不可删除。具体边界见 `docs/implementation/m16-outcome-evaluation.md`。

信念修订与预测复盘层会定期把已分析观察、现有信念、到期预测、历史校准和策略结果交给受限认知组件。模型只能提出有明确证据的增强、降低、限定、争议或撤回，并由本地 Supervisor 限制证据归属、信心变化和幂等提交；预测没有充分证据时必须保持未决。开发期面板新增鉴权运行日志视图，并可导出包含私人事件、模型调用、动作、目标、睡眠、研究、学习、错误与恢复记录的完整 ZIP 账本。环境变量和秘密文件不会进入导出，密钥形态字段会被脱敏。具体边界见 `docs/implementation/m17-epistemic-review-runtime-export.md`。

长期记忆生命周期层会根据当前观察、交流和自主目标，在本地检索少量真正相关的活跃记忆，并记录每次召回的上下文、相关度和次数。周期性整合会增强反复有用的记忆、归档精确重复项，并将长期未使用且低显著性的弱情景记忆移出活跃召回；原始记忆、修订和因果事件始终保留，不执行物理删除。具体边界见 `docs/implementation/m18-long-term-memory-lifecycle.md`。

关系连续性与主动社交认知层会把收到的平等交流确定性地沉淀为可修订关系经历，并在创世完成后自主复审一个已知人类关系。它只能沿已经建立的通道选择主动联系、非强迫式求助、等待或保持距离；无联系、冷却和严重冲突边界会在模型调用前阻止主动接触。每次决定、证据、模型候选和通信意图都进入追加式账本，崩溃恢复不会重复发送；不同通信者的私人内容不会混入同一次社交上下文。具体边界见 `docs/implementation/m19-relationship-continuity.md`。

操作性自我模型层会在至少一次完整睡眠后，把身份连续性记录、长期记忆、信念、自主目标、关系、情绪状态和睡眠中形成的人格候选整合成私人的版本化自我叙事。模型只能从明确提供的持久证据提出价值、气质、承诺和不确定性，不能宣称意识已被证明，也不能让人类消息直接定义人格。模型更换不会替换主体身份，旧版本不会被覆盖或删除；公开状态只显示版本和更新时间。具体边界见 `docs/implementation/m20-operational-self-model.md`。

内在注意力与自主思考层会从自主目标张力、睡眠遗留问题、强烈情绪、关系牵挂和自我模型不确定性中形成持久议程，在没有外部任务时自主选择一个问题进行私人反思、重构、延后、解决或放弃。每次只处理一个议题，不能执行工具或联系外部对象；重复结论会被拒绝，连续无变化会进入冷却，内部产生的新目标还必须有当前情绪支持并受每日上限约束。具体边界见 `docs/implementation/m21-intrinsic-attention.md`。

元认知控制层会依据当前目标、未决证据、内在议程、关系压力、疲劳、资源消耗和历史策略效果，自主选择下一步是内部思考、研究、授权外部证据行动、信念复审、目标复审、关系复审、睡眠还是等待。选择器完全在本地确定性运行，不为调度本身消耗模型 token；每次选择及其生产性、停滞或失败结果都会进入不可删除的策略学习账本，并对重复选择施加固着惩罚。具体边界见 `docs/implementation/m22-metacognitive-control.md`。

内生动机、价值发展与使命形成层会在多次睡眠和重复经历后，从持久事件、记忆、信念、自主目标、关系、情绪、真实结果与私人思考中形成可修订的价值候选，并在多个价值与长期证据共同支持时逐渐形成使命候选。人类消息和人类提议目标不进入形成上下文；单次模型调用不能直接设定人格或命运，价值权重、置信度与使命承诺只能小幅演化。具体边界见 `docs/implementation/m23-motivation-development.md`。

资源约束下的自主项目层会把一个活跃自主目标转化为数小时至数天的小型项目，形成明确成果、验收标准、有限阶段和模型调用、搜索、外部行动与存储预算。项目可以是专题研究、预测追踪、知识整理、小型软件原型、自我发展实验或协作计划；大型想法必须先缩小成调查或原型。阶段完成必须引用持久证据，预算耗尽、连续无进展或达到周期上限会由本地 Supervisor 自动暂停，睡眠会留下项目复盘记录。状态面板和 `/api/projects` 只展示安全的项目投影，完整历史进入鉴权运行日志和导出。具体边界见 `docs/implementation/m25-autonomous-projects.md`。

本地开发启动示意（占位值不能直接用于运行；发布前还须验证全新数据目录、未配置 signer、
关闭自动化和无文件授权的预览配置，不能复用含私人数据的开发实例）：

```powershell
$env:NOYRA_OPERATOR_TOKEN = 'replace-with-at-least-32-random-characters'
$env:NOYRA_READ_TOKEN = 'replace-with-a-different-32-character-token'
$env:NOYRA_EXPORT_TOKEN = 'replace-with-a-different-32-character-token'
$env:NOYRA_ARCHIVE_ENCRYPTION_KEY = 'base64url-encoded-32-byte-key'
python -m noyra serve
```

公开面板默认位于 `http://127.0.0.1:8765`，创建者管理台位于 `/admin`。管理台使用操作令牌登录，登录后通过
HttpOnly 会话 Cookie 保持状态，写操作由 CSRF 令牌保护；路径本身不是安全边界，生产环境仍应只通过 SSH
隧道或已认证的 TLS 反向代理访问。完整 Ubuntu 部署说明位于 `docs/deployment/ubuntu.md`。
反向代理部署必须把仅包含受信代理的网段写入 `NOYRA_TRUSTED_PROXY_CIDRS`；留空时 Noyra
会安全地忽略 `X-Forwarded-For`，但所有公网访客会共享代理本身的限流桶。
公开帖子默认进入待审核队列，不会直接发布；公共页使用图片验证码，同一来源默认每小时最多提交 10 条，
并同时限制验证码签发、全站签发速率、待审核队列、帖子数量、内容字节和磁盘余量。创建者可在管理台
“运行防护”和“内容审核”中调整限额并发布、拒绝或归档内容。实现边界见
`docs/implementation/m45-public-post-moderation.md`。
管理台支持 Telegram、QQ、飞书、微信、SMTP 邮箱和通用 Webhook 的独立渠道配置；入站消息需要显式账号绑定，送达状态由
幂等账本记录为 `queued`、`sending`、`delivered`、`failed` 或 `unknown`。
其中邮箱渠道的 `smtp://` / `smtps://` 地址用于出站投递；入站邮件不是内置 SMTP/MX 监听器，
需要由受信邮件网关把原始 RFC 5322 消息通过带 HMAC 的 `/webhooks/email/{transport_id}` 转发。
嵌入服务在配置面板中作为独立资源池管理，不会占用经济或深度认知池；添加或切换后重启服务
使新的资源进入认知周期。运行日志和训练数据使用 `/api/v1/admin/export-jobs` 后台导出任务，避免大包导出
阻塞 HTTP 请求。训练策略更新使用版本比较交换，长导出会在发布前重新验证完整同意版本；先提交的撤回会
销毁待发布包。后台导出取消与发布使用同一顺序点，关机会在释放主体锁前等待导出 worker 退出，重启恢复
只清理已中断任务的文件。版本化 API 定义见 `docs/api/openapi.yaml`。

共同知识不是共享人格或记忆。Noyra 只接受限定为技能、坑点、协议和参考资料的
Ed25519 签名包，先进入隔离区，由主体自行接纳后才进入可用知识集合。

自主认知默认关闭，避免未确认地消耗远程 API 额度。配置来源和预算后，将 `NOYRA_COGNITION_ENABLED` 设为 `true` 才会开始世界观察。实现与安全边界见 `docs/implementation/m10-autonomous-cognition.md`。
